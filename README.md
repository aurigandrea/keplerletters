# keplerletters

Visualising the Kepler correspondence --
Using Digital Humanities approaches in the History of Astronomy

Inspired by Schich et al. 2014 and Ahnert and Ahnert 2023, the project explores both the network and the geographical footprint of Kepler's correspondence. Designed as teaching material, turned into research.

# About the Repo

The repository contains two parts:

- Research pipeline: scrape, transform, geocode, and build network/map data.
- UI: a landing page for the interactive visualisations.

## Project Data

This work is based on data from **EMLO (Early Modern Letters Online)**, Cultures of Knowledge, University of Oxford. https://emlo.bodleian.ox.ac.uk/

## Repository Structure

- `scripts/`
  - Research/build scripts (scraping, geocoding, network files, map outputs)
- `data/`
  - All research data outputs (CSV files)
- `website/`
  - Landing page and visualisation website assets
- `website/assets/`
  - CSS and JavaScript used by the visualisations
- `website/visualizations/`
  - Interactive HTML visualisations generated by the scripts.

## Core Outputs

Research CSV outputs in `data/`:

- `emlo_kepler_letters.csv`
- `places.csv`
- `person_locations.csv`
- `nodes.csv`
- `edges.csv`

Website visual outputs in `website/visualizations/`:

- `multiview_map.html`
- `timeline_map.html`
- `network_graph.html`

## Typical Workflow

Run from repository root.

1. Build the letters dataset (if needed)

```bash
python scripts/scrape_emlo_kepler.py
```

2. Build people network CSV files

```bash
python scripts/build_network_files.py
```

3. Geocode places

```bash
python scripts/geocode_places.py
```

4. Build website visualisations

```bash
python scripts/build_multiview_map.py
python scripts/build_timeline_map.py
python scripts/build_network_graph.py
```

5. Open the landing page

```bash
open website/index.html
```

## Optional Filter for Cleaner Network Graph

Show only stronger person-to-person ties:

```bash
python scripts/build_network_graph.py --min-weight 3
```
